# UniDeal POS — APK releases

Repo chỉ chứa **GitHub Releases** (file `.apk`). Không commit source hay APK vào `main`.

Manifest in-app updater (copy lên `https://unideal.dev4fun.vn/apk/version.json`):

`https://raw.githubusercontent.com/NTHKiris/unideal-releases-app/main/version.json`

Tải APK theo tag, ví dụ:

`https://github.com/NTHKiris/unideal-releases-app/releases/download/v1.0.3/unideal-pos-1.0.3.apk`
